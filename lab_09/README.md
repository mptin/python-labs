## Что делает CI

Пайплайн `lab-check` запускается автоматически при пуше в `main` и при
создании pull request. Шаги:

1. устанавливает зависимости из `requirements.txt`;
2. выполняет `lab.ipynb` целиком через `nbconvert --execute`;
3. дописывает в последнюю ячейку отметку о выполнении раннером;
4. собирает HTML-отчёт;
5. публикует `executed_lab.ipynb` и `report.html` как артефакты сборки.

Оба артефакта скачиваются со страницы запуска пайплайна.

## Отметка о выполнении раннером (пункт 5 задания)

По заданию раннер должен дописывать в ноутбук текст, доказывающий, что код
выполнен в CI, а не локально и не в Google Colaboratory. Занимается этим
`ci_signature.py`.

Первая версия скрипта искала переменные окружения с префиксами `CI_`,
`SOURCECRAFT_` и подобными, и если хоть одна находилась, писала «выполнено
раннером». Подделать такую отметку можно одной строкой:

```bash
CI_COMMIT_SHA=deadbeef python ci_signature.py lab.ipynb
```

После этого ноутбук утверждает, что собран в CI, а в соседней строке той же
таблицы стоит имя моего ноутбука и путь `/Users/...`. Доказательство, которое
опровергает само себя, хуже, чем никакого.

Поэтому проверок стало четыре, и «выполнено раннером» пишется, только если
сходятся все:

| Проверка | Как проверяется |
|---|---|
| Переменные окружения раннера | есть переменные с известными префиксами |
| Операционная система Linux | `platform.system() == "Linux"` |
| Запуск в контейнере | есть `/.dockerenv` либо `docker`/`containerd`/`kubepods` в `/proc/1/cgroup` |
| Не Google Colab | не задана `COLAB_RELEASE_TAG` и нет каталога `/content` |

В отметку попадает таблица со всеми четырьмя проверками и тем, что по каждой
нашлось, плюс время выполнения, имя хоста, версия Python и переменные раннера.
Если сошлись не все, заголовок меняется на «локальный запуск», а текст прямо
перечисляет, чего не хватило.

### Нюансы реализации

Порядок шагов в CI менять нельзя. Отметка добавляется после
`nbconvert --execute`. Если поменять шаги местами, nbconvert перезапишет файл
результатом выполнения, и отметка бесследно исчезнет. HTML собирается
последним, уже из подписанного ноутбука, иначе отметка попадёт в `.ipynb`, но
не в отчёт.

Повторный запуск не плодит отметки: предыдущая находится по скрытому маркеру
`<!-- ci-signature -->` и заменяется новой.

Список переменных CI собирается по префиксам (`CI_`, `SOURCECRAFT_`, `SC_`,
`JOB_`, `RUNNER_` и другим), а не по фиксированным именам. Так отметка не
сломается, если платформа переименует переменные или добавит новые.

`executed_lab.ipynb` и `report.html` в репозитории не лежат: их создаёт
пайплайн, скачивать надо со страницы запуска. Хранить в репозитории копию,
собранную локально, смысла нет, а путаницы от неё много.

## Нюансы самой работы

### Почему `%matplotlib inline`, а не бэкенд `Agg`

В работе с NumPy графики сохранялись в файлы, и для этого нужен бэкенд `Agg`.
Здесь он не подходит: при `Agg` картинки не попадают в вывод ячейки, и
HTML-отчёт, который собирает CI, окажется без графиков. Инлайновый бэкенд
работает и без графического окружения, поэтому в контейнере всё строится
нормально.

### Ячейки с выводами переведены в markdown

В шаблоне текстовые выводы под графиками были заготовлены как ячейки с кодом
(`# Ваш вывод`). Требование README — «под каждым графиком должен быть краткий
текстовый вывод», а текст естественнее оформлять markdown-ячейкой: так он
нормально выглядит и в ноутбуке, и в HTML-отчёте.

### Ноль баллов по математике — не ошибка данных

Минимум по математике равен 0, и первым делом это выглядит как брак. Проверка
строки целиком показала, что у того же студента 17 и 10 баллов по другим
предметам, то есть результат согласованный и удалять его нельзя.

## Основные результаты

Датасет: 1000 студентов, 8 исходных признаков, пропусков и дубликатов нет.

| Фактор | Разница в среднем балле |
|---|---|
| Образование родителей (магистр против школы) | 10.5 |
| Тип обеда (стандартный против льготного) | 8.6 |
| Подготовительный курс (пройден против нет) | 7.6 |
| Пол (девушки против юношей) | 3.7 |

Различие по полу переворачивается в зависимости от предмета.

| Предмет | Девушки | Юноши |
|---|---|---|
| Математика | 63.63 | 68.73 |
| Чтение | 72.61 | 65.47 |
| Письмо | 72.47 | 63.31 |

По среднему баллу разница составляет лишь 3.7 балла — усреднение маскирует
противоположно направленные различия в 5-9 баллов.

Подробные выводы по каждому графику — в самом ноутбуке.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook lab.ipynb
```

Воспроизвести то, что делает CI:

```bash
jupyter nbconvert --to notebook --execute --output executed_lab.ipynb lab.ipynb
python ci_signature.py executed_lab.ipynb
jupyter nbconvert --to html --output report.html executed_lab.ipynb
```
