## Что реализовано

### 1. Создание и обработка массивов

| Функция | Что делает | Ключевой инструмент |
|---|---|---|
| `create_vector` | массив `[0..9]` | `np.arange(10)` |
| `create_matrix` | матрица 5×5 из случайных чисел `[0, 1)` | `np.random.rand(5, 5)` |
| `reshape_vector` | меняет форму `(10,)` в `(2, 5)` | `vec.reshape(2, 5)` |
| `transpose_matrix` | транспонирование | `mat.T` |

### 2. Векторные операции

Сложение, умножение на скаляр и поэлементное умножение записываются обычными
операторами `+` и `*`, NumPy применяет их сразу ко всему массиву. Это
векторизация: цикл `for` не нужен, операция выполняется в скомпилированном коде
и работает в разы быстрее.

`dot_product` — скалярное произведение через `np.dot(a, b)`, то есть сумма
попарных произведений элементов.

### 3. Матричные операции

* `matrix_multiply` — `a @ b`, матричное умножение (строка на столбец);
* `matrix_determinant` — `np.linalg.det(a)`;
* `matrix_inverse` — `np.linalg.inv(a)`;
* `solve_linear_system` — `np.linalg.solve(a, b)` для системы `A @ x = b`.

### 4. Статистический анализ

`load_dataset` читает CSV через pandas и сразу переводит его в массив NumPy
(`.to_numpy()`), потому что дальше удобнее работать с числовым массивом.

`statistical_analysis` возвращает словарь: `mean`, `median`, `std`, `min`,
`max`, `p25`, `p75`.

`normalize_data` — min-max нормализация по формуле `(x - min) / (max - min)`:
любые данные приводятся к диапазону `[0, 1]`.

Результат для оценок по математике из учебного датасета:

```
mean: 81.50   median: 84.50   std: 10.51
min: 60.00    max: 95.00      p25: 74.25   p75: 89.50
```

### 5. Визуализация

* `plot_histogram` — гистограмма распределения оценок;
* `plot_heatmap` — тепловая карта корреляции предметов (`np.corrcoef`);
* `plot_line` — график «номер студента в балл».

Все три сохраняют результат в папку `plots/`.

## Нюансы, с которыми пришлось разобраться

При запуске тестов графического окна нет, поэтому в начале модуля включается
бэкенд `Agg` (`matplotlib.use("Agg")`) и графики рисуются прямо в файл. Без
этого тесты визуализации зависают или падают в окружении без GUI.

После каждого графика вызывается `plt.close()`. Matplotlib рисует всё в одну
«текущую» фигуру, и если её не закрывать, второй график накладывается на
первый. Сохранение и закрытие вынесены во вспомогательную функцию `_save_plot`.

`np.std` по умолчанию считает смещённое отклонение: делит на `n`, а не на
`n - 1`. Для несмещённой оценки нужен `np.std(data, ddof=1)`.

Min-max нормализация ломается, если все элементы массива равны: тогда
`max - min = 0` и получается деление на ноль. В учебных данных такого нет, но
в реальном коде этот случай надо обрабатывать отдельно.

Отдельная история вышла с длиной строк. Я отформатировал код через `black`,
а он по умолчанию укладывается в 88 символов, тогда как `flake8` без настроек
проверяет по 79. В результате линтер выдавал ошибки E501 на ровном месте,
хотя код выглядел аккуратным. Вариантов два: поднять лимит в конфиге или
уложиться в 79. Я выбрал второе и поправил три строки руками, чтобы `flake8`
запускался без дополнительных аргументов и проходил.

По требованиям DAST/DATS весь код снабжён аннотациями типов (PEP 484) и
докстрингами (PEP 257), проверен `flake8` на соответствие PEP 8 и покрыт
тестами. Все 17 тестов проходят.

## Выводы

NumPy позволяет описывать операции над целыми массивами одной строкой: вместо
явных циклов используются операторы и функции, работающие сразу над всеми
элементами. Код от этого становится короче и быстрее. Связка
NumPy + pandas + matplotlib/seaborn закрывает полный цикл от загрузки данных
до визуализации.
